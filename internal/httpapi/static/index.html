MCPic
上传画廊
self-hosted image bed

让 AI Agent 上传图片像写文件一样自然

MCPic 是一个自托管图床：接收图片、格式转换与缩放、返回可直接引用的链接与 Markdown。零配置、单二进制、无外部依赖。

快速开始

01 · 启动

Docker 一键运行

docker run -d -p 8080:8080 \ -v mcpic-data:/data \ -e MCPIC_API_KEY=your-secret-key \ mcpic/mcpic:latest
02 · 上传

curl 直接传图

curl -X POST http://localhost:8080/api/upload \ -H "X-API-Key: your-secret-key" \ -F "file=@screenshot.png"
03 · 拿链接

返回 URL 与 Markdown

{ "url": "{{.BaseURL}}/i/abc123", "markdown": "![image]({{.BaseURL}}/i/abc123)", "size": 184320, "width": 1920, "height": 1080, "format": "webp" }

MCP 配置（Claude Code 等 Agent）

MCP 配置 JSON

{ "mcpServers": { "mcpic": { "command": "/usr/local/bin/mcpic", "args": ["mcp"], "env": { "MCPIC_STORAGE_PATH": "/data/uploads", "MCPIC_API_KEY": "your-secret-key", "MCPIC_BASE_URL": "{{.BaseURL}}" } } } }

配置后 Agent 可调用 upload_image，支持 path（本地绝对路径）、url（远程图片）、data（base64）三种来源，可选 format（webp/original）与 max_width（默认 1920）。

API 速查

方法路径说明
POST/api/upload上传（multipart 或 JSON base64），需 X-API-Key
GET/i/:key访问图片（浏览器打开显示预览页，?raw=1 取原图）
GET/healthz健康检查
AGPL-3.0-only PRD v3.2 上传自动转 WebP · 最大 10MB（超 3MB 网页端预压缩，API 直传不限）· PNG/JPEG → WebP(85) · 超宽等比缩放
